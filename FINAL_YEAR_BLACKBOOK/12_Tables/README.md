# Tables — Stage 1

This folder contains the clean tabular versions of the Stage 1 results, for
direct inclusion in the black book report.

| File | Content |
|---|---|
| `dataset_split.md` | Train/validation/test image and scene counts |
| `dataset_class_distribution.md` | Per-class positive image counts |
| `training_configuration.md` | Hyperparameters and environment used for all four experiments |
| `model_comparison.md` | Full validation + held-out test comparison across all four models |
| `b0_per_class_test_results.md` | EfficientNet-B0's full per-class held-out test table |
| `per_model_failure_summary.md` | Failure counts (FP/FN/incorrect images) per model |
| `dataset_limitations.md` | Tabulated dataset limitations |

All values are copied from the confirmed Stage 1 results in
`06_AI_Model_Development/`; none are estimated.
