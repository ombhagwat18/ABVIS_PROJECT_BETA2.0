# Figures and Graphs — Stage 1

All charts below were generated by `_generate_charts.py` in this folder,
using only the actual recorded values confirmed in
`06_AI_Model_Development/Test_Evaluation/HELD_OUT_TEST_RESULTS.md` and each
checkpoint's `metrics.json`. No values were estimated or invented. Re-run
`python _generate_charts.py` from this folder to regenerate the PNGs if the
recorded values in that script are updated to match a future re-evaluation.

| File | Content |
|---|---|
| `model_test_macro_f1.png` | Held-out test macro-F1 per model |
| `model_exact_match_accuracy.png` | Held-out test exact-match accuracy (%) per model |
| `model_false_positive_comparison.png` | Total false-positive label instances per model |
| `model_false_negative_comparison.png` | Total false-negative label instances per model |
| `model_inference_fps.png` | Held-out test inference FPS (live-scoring methodology) per model |
| `model_size_comparison.png` | Checkpoint (`model.pt`) size in MB per model |
| `training_time_comparison.png` | Total training time (seconds) per model |

This folder does not modify, read from, or write to the ML project's
`projects/` directory — the values were copied by hand into
`_generate_charts.py` from the confirmed Stage 1 evaluation results.
